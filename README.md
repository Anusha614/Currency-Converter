# Currency Converter

This is a simple currency converter web application built using React and Tailwind CSS. 

I built this project purely for practice to learn the fundamentals of React, handle API data fetching, and understand how to manage state across components.

## Features
* Fetches real-time currency exchange rates from an external API.
* Allows users to input an amount and convert it between different global currencies.
* Reusable input box components for selecting currencies and entering values.

## Why I Built This (Learning Objectives)
* To practice creating custom hooks (`useCurrencyInfo`) for fetching data.
* To understand how `onChange` events and `e.target.value` work in React forms.
* To learn how to loop through data arrays using `.map()` and understand why React requires unique `key` props.
* To practice clean file structures using the barrel export pattern (`index.js`).
